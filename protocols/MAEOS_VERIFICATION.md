# MAEOS verification

Configuration is intent, not runtime proof. Deterministic profile, gate, compiler, manifest, and installed-file checks prove only their respective local contracts. Report runtime model/effort only from direct runtime metadata. If a fresh-session/native smoke cannot be observed, record `UNRUN` with the capability reason; never infer success from TOML.

Independent review is required for security/privacy, auth, migrations/data invariants, cross-cutting diffs, repeated verification failure, owner request, or material uncertainty. Review and all work stop when accepted criteria are green unless a concrete new risk or explicit owner instruction requires more.
