# Chat Start Protocol

1. Identify the task and whether account-wide context is relevant.
2. If relevant, read [`../START_HERE.md`](../START_HERE.md).
3. Use [`../CONTEXT_INDEX.md`](../CONTEXT_INDEX.md) to retrieve only necessary files.
4. For project work, consult [`../projects/PROJECT_REGISTRY.md`](../projects/PROJECT_REGISTRY.md).
5. Treat the current chat instruction as highest authority.
6. Do not load the full vault.
7. Do not modify the vault unless explicitly asked.
