# Conflict Resolution Protocol

## Steps

1. Detect the conflicting statements.
2. Identify each source and date.
3. Compare authority levels.
4. Give Earl's current explicit instruction first priority.
5. Prefer the active project's authoritative repository for project facts.
6. Do not silently merge materially different statements.
7. Mark the older statement as superseded when replacement is confirmed.
8. Update links, indexes, and changelogs.
9. Preserve historical context only when it remains useful.
10. State unresolved uncertainty clearly.

## Required record for supersession

- Old statement
- New statement
- Date of change
- Source of authority
- Reason
- Affected files
