# Redaction Checklist

Before committing any context, verify that the change contains no:

- [ ] Passwords
- [ ] API keys
- [ ] Personal access tokens
- [ ] Session cookies
- [ ] Recovery codes
- [ ] Private keys or certificates
- [ ] Exact residential addresses
- [ ] Government identifiers
- [ ] Banking or payment credentials
- [ ] Confidential third-party information
- [ ] Private messages copied without need
- [ ] Unnecessary health details
- [ ] Raw chat dumps
- [ ] Hidden metadata
- [ ] Unexpected attachments
- [ ] Unsupported factual claims
- [ ] Invented repository links
- [ ] Temporary speculation mislabeled as stable context

Also confirm that the update is minimal, relevant, and properly classified.
