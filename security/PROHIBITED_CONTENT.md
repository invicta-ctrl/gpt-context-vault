# Prohibited Content

The following must not be committed:

- Passwords
- API keys
- Personal access tokens
- Cookies or session tokens
- Recovery codes
- Private SSH keys
- Service-account credentials
- Government identification numbers
- Banking credentials
- Exact residential addresses
- Unnecessary medical records
- Raw ChatGPT exports used as active memory
- Unauthorized confidential information
- Sample credentials that resemble real credentials
- Secrets hidden in attachments or metadata

Archived material is not exempt from this policy.
