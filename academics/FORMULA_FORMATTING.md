# Formula Formatting

Use proper LaTeX notation for mathematical formulas.

## Rules

- Do not present equations as ambiguous plain text when mathematical formatting is appropriate.
- Use subscripts for indexed variables.
- Use superscripts for powers.
- Use stacked fractions.
- Put important formulas in centered display equations.
- Define symbols and units.
- Maintain dimensional consistency.
- Align multi-step derivations when helpful.

## Examples

\[
R_u = \frac{M_u}{\phi b d^2}
\]

\[
A_{nv} = A_{gv} - n d_h t
\]

These examples demonstrate formatting only. Governing equations must still be verified for the actual problem and applicable standard.
