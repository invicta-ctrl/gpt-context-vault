# Archive

The archive is for historical material that should not be treated as active context.

## Appropriate content

- superseded summaries retained for traceability;
- retired project overviews;
- historical decisions with continuing reference value;
- reviewed records that no longer belong in active retrieval.

## Rules

- Archived content is not active by default.
- Do not archive material merely to avoid deciding whether it is still valid.
- Raw chats are not automatically trustworthy or authoritative.
- Secrets remain prohibited.
- Archived information must not override current instructions or active project sources.
