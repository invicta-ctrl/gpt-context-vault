# Project Context Prompt

Use `gpt-context-vault` for stable user context and cross-project operating rules.

Use the active project's own repository as the authority for requirements, code, decisions, implementation status, tests, and documentation.

Before implementing:

1. Verify the current repository state.
2. Identify authoritative project files.
3. Preserve approved requirements unless explicitly replaced.
4. Identify conflicting or superseded information.
5. Distinguish confirmed requirements, assumptions, proposals, and completed work.

After substantial work, provide a project handoff with changed files, behavior completed, tests and exact results, unresolved issues, risks, and the next recommended task.
