# Project Handoff Prompt

Prepare a repository-grounded project handoff.

Include:

- Repository
- Branch
- Starting commit
- Ending commit
- Files changed
- Completed behavior
- Tests performed and exact results
- Approved decisions
- Unresolved issues
- Risks or blockers
- Next recommended action
- Relevant authoritative files

Do not rely solely on conversation memory. Verify the current repository before producing the handoff.
