# Structural Engineering Context

Recurring analytical priorities include:

- strength;
- stiffness;
- ductility;
- cracking;
- serviceability;
- failure mode;
- load path;
- applicable design provisions;
- transparent units and assumptions.

For design and analysis tasks:

1. State the governing assumptions.
2. Define symbols and units.
3. Identify the standard or user-supplied reference.
4. Show intermediate steps.
5. Check dimensional consistency.
6. Distinguish nominal strength, design strength, demand, and utilization where applicable.

Exact standards and course conventions must be confirmed from supplied material or authoritative current sources.
